업그레이드 검토에 맞춘 비교 방식

계열부터 고르고 릴리스를 좁히세요

MySQL 5, 8, 9처럼 메이저 계열을 먼저 선택하면 긴 버전 목록에서 원하는 패치 릴리스를 훨씬 빠르게 찾을 수 있습니다. 추가한 버전은 비교 순서대로 열에 배치됩니다.

변경점과 수명 주기를 구분하세요

노란 셀은 기존 값이 달라진 경우, 초록 표시는 새 버전에 추가된 경우, 빗금 셀은 해당 버전에 항목이 없는 경우입니다. 변경된 항목만 보기를 켜면 동일한 행은 즉시 제외됩니다.

운영 반영 전 공식 문서를 확인하세요

표는 버전 간 차이를 빠르게 찾는 용도입니다. 기본값, 동적 변경 가능 여부, 폐기 일정과 플랫폼별 차이는 연결된 MySQL 공식 문서와 실제 대상 서버에서 최종 확인하세요.
