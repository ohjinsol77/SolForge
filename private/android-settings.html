Grand Koleos ADB / Developer Settings Test

목적

Grand Koleos / RCOS 차량 브라우저에서 Android 내부 Settings 화면을 직접 호출할 수 있는지 확인하는 진단 페이지입니다.

확인할 항목: Developer Options, USB Debugging, Wireless Debugging, ADB 관련 설정.

테스트 방법
OPEN 버튼을 누른 뒤 설정 화면이 열리면 열림, 아무 반응이 없으면 안 열림, 오류나 페이지를 열 수 없다는 메시지가 나오면 오류를 누르세요. 설정 화면이 열리면 사진을 찍어두세요.
중요

먼저 1-1 기본 Android Settings가 열리는지 확인하세요. 기본 설정도 열리지 않으면 개발자 옵션 자체의 문제보다 Whale / RCOS가 Android Intent 실행을 차단했을 가능성이 큽니다.

우선순위: 1-1 → 1-2 → 2-1 → 2-2 → 2-3 → 3-1 → 4-1 → 5-3 → 6-5

7. 결과 해석

CASE 1
기본 Settings도 전부 안 열림
→ Whale이 Intent 실행을 막거나 RCOS가 외부 Activity 실행을 차단했을 가능성이 큽니다.


CASE 2
기본 Settings는 열리는데 Developer Options만 안 열림
→ Developer Options Activity가 비활성화됐을 수 있습니다. Engineering / Factory 메뉴에서 활성화 경로를 찾아보세요.


CASE 3
Device Info가 열림
→ Build Number / Android Version / Software Version을 확인하고 기존 Renault 설정과 다른 Build Number가 있는지 살펴보세요.


CASE 4
2-3 또는 3-1이 열림
→ Android Automotive Developer Options에 접근했을 가능성이 높습니다. USB / Wireless Debugging을 확인하세요.


CASE 5
USB Settings가 열림
→ USB Mode / Debug / ADB / MTP 메뉴를 확인하세요.


CASE 6
Install Unknown Apps가 열림
→ APK 직접 설치 경로가 활성화되어 있을 수 있습니다.


CASE 7
특수 권한 화면도 대부분 열림
→ 브라우저 Intent 제한은 크지 않을 수 있습니다. RCOS 내부 패키지명이나 Activity 이름을 찾는 방향으로 진행하세요.
